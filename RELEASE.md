# Building a Release APK for the Demo

This walks through producing a signed `.apk` you can sideload onto an Android
phone for the Lilly demo. Do this once per demo device; the APK is not going
through Play Store review.

## Prerequisites

- Flutter toolchain up and running: `flutter doctor` should be all-green.
- The app should already run in debug: `flutter run` from this directory should
  install a debug build to your device or emulator successfully.
- Java 17+ (comes with Android Studio; also needed for `keytool`).

## 1. Generate a signing key (one time)

Debug builds use a Flutter-provided debug key. Release APKs must be signed by
you. Generate a keystore in a **safe location outside the repo** (never commit
`.jks` files):

```powershell
# Windows PowerShell
$keystoreDir = "$env:USERPROFILE\.android-keys"
mkdir $keystoreDir -Force
keytool -genkey -v `
  -keystore "$keystoreDir\habitnu-nu-release.jks" `
  -keyalg RSA -keysize 2048 -validity 10000 `
  -alias habitnu-nu
```

You'll be prompted for:
- Keystore password (pick one, remember it — cannot be recovered)
- First/last name, org unit, org, city, state, country code
- Key password (can be same as keystore password)

Note the full path to the `.jks` file — you'll reference it below.

## 2. Wire the keystore into the Flutter build

Create `android/key.properties` (this file is git-ignored by the Flutter
default `.gitignore`):

```properties
storePassword=YOUR_KEYSTORE_PASSWORD
keyPassword=YOUR_KEY_PASSWORD
keyAlias=habitnu-nu
storeFile=C:/Users/YOUR_USER/.android-keys/habitnu-nu-release.jks
```

Use forward slashes on Windows. Do not put quotes around values.

Then edit `android/app/build.gradle` (generated by `bootstrap.ps1`). Near the
top, add:

```gradle
def keystoreProperties = new Properties()
def keystorePropertiesFile = rootProject.file('key.properties')
if (keystorePropertiesFile.exists()) {
    keystoreProperties.load(new FileInputStream(keystorePropertiesFile))
}
```

Inside `android { ... }`, add a `signingConfigs` block and reference it from
`buildTypes.release`:

```gradle
android {
    // ...existing lines...

    signingConfigs {
        release {
            keyAlias keystoreProperties['keyAlias']
            keyPassword keystoreProperties['keyPassword']
            storeFile keystoreProperties['storeFile'] ? file(keystoreProperties['storeFile']) : null
            storePassword keystoreProperties['storePassword']
        }
    }

    buildTypes {
        release {
            signingConfig signingConfigs.release
            minifyEnabled false
            shrinkResources false
        }
    }
}
```

## 3. Build the release APK

```powershell
cd C:\Sarvaantar\Habitnu\Lilly-Dashboard\Habitnu-Lilly Dashboard\mobile\habitnu_nu
flutter clean
flutter pub get
flutter build apk --release
```

The output is at:

```
build\app\outputs\flutter-apk\app-release.apk
```

Rename it for clarity if you're versioning demos:

```powershell
Copy-Item build\app\outputs\flutter-apk\app-release.apk `
          "$env:USERPROFILE\Desktop\habitnu-nu-demo-$(Get-Date -Format 'yyyy-MM-dd').apk"
```

Expect around 25–35 MB.

## 4. Install on the demo phone

**Option A: USB (fastest)**

Enable USB Debugging on the phone (Developer Options), plug in, then:

```powershell
flutter install
```

Or with plain `adb`:

```powershell
adb install -r "$env:USERPROFILE\Desktop\habitnu-nu-demo-2026-07-05.apk"
```

**Option B: Sideload without dev tools**

1. Copy the APK to the phone (email to yourself, Google Drive, USB transfer).
2. On the phone: tap the APK in the file manager.
3. When Android says *"For your security, your phone is not allowed to install
   unknown apps from this source"*, tap Settings → toggle **Allow from this
   source** → back to the install prompt → Install.

## 5. First-launch sanity checks

- App icon should read **"Nu — Habitnu"**.
- On first tap of the mic button, Android will prompt for microphone permission.
  Grant it.
- Voice test: press mic, say **"Whatsup Nu, open CGM"**. Nu should say
  *"Opening CGM"* and navigate.
- CGM screen should show 14 day chips, TIR ring animating to 99%, six-lens
  strip, 24-hour glucose curve with meal/activity/hydration dots, AGP overlay.

If any of those don't render, the most likely cause is missing bundled JSON:

```powershell
cd C:\Sarvaantar\Habitnu\Lilly-Dashboard\Habitnu-Lilly Dashboard\glp1-dashboard
npm run export-mock-data
# then rebuild the APK
```

## Troubleshooting

**"cmdline-tools component is missing" during flutter doctor**
Open Android Studio → SDK Manager → SDK Tools tab → check **Android SDK
Command-line Tools** → Apply.

**"Execution failed for task ':app:validateSigningRelease'"**
Your `key.properties` path is wrong or the keystore file is missing at that
path. Verify with `Test-Path` in PowerShell.

**Voice recognition doesn't work on the phone**
- Confirm the phone has the Google app installed (provides SpeechRecognizer).
- Confirm the phone has internet (Google's on-device STT still often
  requires connectivity for the first models to load).
- On some OEM Android skins (Xiaomi MIUI, some OPPO builds), background mic
  access is restricted per-app. Long-press the app icon → App info →
  Permissions → allow Microphone.

**"App not installed" error on install**
If a previous debug build is installed, uninstall it first. Debug and release
builds have different signatures, so Android won't let one replace the other.
